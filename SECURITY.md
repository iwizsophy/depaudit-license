# Security Policy

Japanese version is available at [SECURITY.ja.md](/D:/Source/Self/license/SECURITY.ja.md).

## Scope

This document is for security vulnerabilities only.

For general usage questions and non-security support, see [.github/SUPPORT.md](D:/Source/Self/license/.github/SUPPORT.md).

## Reporting a vulnerability

Please do not report security issues in public issues.

Use GitHub private vulnerability reporting when it is enabled for the repository.

If private reporting is unavailable, open a temporary issue with only:

- `Security report requested`

and no technical details. Maintainers will move communication to a private channel when possible.

## Disclosure policy

- coordinated disclosure after a fix is available
- release notes should describe affected versions or affected release lines when known
- mitigation or workaround guidance should be included when a full fix is not immediately available
